MARINOVANI — установка поверх существующего сайта

В архиве дополнение к GameX, а не полный сайт. Ваши index.html и изображения остаются на сервере.
Не удаляйте существующий проект. Перед копированием сохраните копию docker-compose.yml.

1. В BotFather: /revoke -> выберите @imangelo_bot -> получите новый токен.
   Старый токен из чата больше не используйте. Новый в чат не отправляйте.

2. Загрузите содержимое этой папки в /home/mihail/marinovani/.
   Новая папка backend должна оказаться рядом с index.html.
   docker-compose.yml заменяет прежний файл (предварительно сохраните его копию).
   Папку assets объедините с существующей, не удаляйте её картинки и стили.
   Если у вас уже есть .gitignore/.dockerignore, добавьте наши строки в свои файлы.

3. В SSH, из папки проекта:
   cd ~/marinovani
   cp .env.example .env
   chmod 600 .env

   Откройте .env в VS Code. Заполните:
   BOT_TOKEN=новый_токен
   OWNER_CHAT_ID=0
   POSTGRES_PASSWORD=длинный_случайный_пароль

   Пароль можно создать командой:
   openssl rand -hex 24

   OWNER_CHAT_ID=0 — временная настройка, чтобы запустить бота и узнать свой ID.
   Не оставляйте 0 в готовом проекте: уведомления с ним не доставляются.

4. Запустите:
   docker compose up -d --build
   docker compose ps

   PostgreSQL с базой и таблицами создаётся автоматически.
   На компьютере или сервере отдельно устанавливать PostgreSQL/Python не нужно.
   Если ошибка:
   docker compose logs --tail=50 bot api db
   Не присылайте .env и вывод docker compose config: там секреты.

5. Откройте https://t.me/imangelo_bot, нажмите Start, отправьте /id.
   Бот покажет ваш числовой Telegram ID.
   Замените OWNER_CHAT_ID=0 в .env на этот ID, сохраните и выполните:
   docker compose up -d bot
   Вы как владелец должны хотя бы раз начать чат с ботом, иначе он не сможет вам писать.

6. Подключите сайт к общей базе. В index.html в месте для карточек зон вставьте:

   <section class="container">
     <h2>Зоны и цены Marinovani</h2>
     <div id="marinovani-zones"></div>
   </section>

   Перед закрывающим </body> вставьте:
   <script src="./assets/js/marinovani-zones.js" defer></script>

   Сохраните и выполните:
   docker compose up -d --build

   Откройте http://89.127.206.24:8100 и обновите Ctrl+F5.
   Новые карточки берут цены из PostgreSQL через API.
   Ваши старые карточки можно удалить вручную после проверки новых.

7. Проверьте:
   http://89.127.206.24:8100/api/health -> {"ok":true}
   http://89.127.206.24:8100/api/zones -> список четырёх зон
   Нажмите на сайте ссылку VIP PC -> в Telegram нажмите Start/Запустить.
   Бот должен сразу написать «Выбрано: VIP PC».
   Пройдите имя -> дату/время -> длительность -> телефон -> подтверждение.
   Владелец получит уведомление с номером заявки.

   Проверить число заявок без раскрытия телефонов:
   docker compose exec db psql -U marinovani -d marinovani -c "SELECT count(*) FROM bookings;"

   Перезапустите:
   docker compose restart
   Снова проверьте число заявок — данные должны сохраниться.

8. Дополнительные ссылки для существующих кнопок:
   https://t.me/imangelo_bot?start=standard_pc
   https://t.me/imangelo_bot?start=vip_pc
   https://t.me/imangelo_bot?start=ps5
   https://t.me/imangelo_bot?start=vip_ps5_shower

УСТРОЙСТВО
site (Nginx, порт 8100) -> api (Python) -> db (PostgreSQL)
bot (Python, Telegram polling) -> та же db
База наружу не опубликована. Внешний порт нужен только сайту.
Токен хранится только в .env, в образ сайта он не копируется.
Данные PostgreSQL находятся в томе pgdata и переживают пересоздание контейнеров.
Не выполняйте docker compose down -v: флаг -v удаляет том с заявками.
Пароль PostgreSQL задаётся при первом создании тома. Для его последующей смены
нужна смена пароля и внутри самой базы, одного редактирования .env недостаточно.

ОГРАНИЧЕНИЯ
Это учебный приём заявок, не автоматическое подтверждение свободных мест.
Ночные тарифы и наличие мест уточняет администратор. Сумма считается по часовому тарифу.
Диалог пользователя тоже хранится в PostgreSQL и переживает перезапуск бота.
Недоставленные уведомления повторяются каждые 10 секунд. При сбое сразу после
отправки возможен повтор уведомления — сверяйте номер заявки.
Часовой пояс задаётся CLUB_TIMEZONE в docker-compose.yml, сейчас Europe/Kaliningrad.
Бот должен работать только в одном экземпляре с этим токеном.
Уведомления доставляются только владельцу из OWNER_CHAT_ID.
